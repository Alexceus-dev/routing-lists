# Списки маршрутизации

Готовые списки для клиентов VPN: что вести напрямую, а что через туннель.
Собираются скриптом из открытых реестров, обновляются раз в неделю сами.

## Что внутри

| Файл | Что это | Строк |
|---|---|---|
| `lists/ru-ipv4.txt` | Российские сети | ~8 700 |
| `lists/cn-ipv4.txt` | Китайские сети | ~5 500 |
| `lists/direct-domains.txt` | Домены прямого пути | ~30 |

Файлы плоские: одна запись на строку, комментарии со знака `#`. Их читает и
человек, и роутер, и телефон.

## Две задачи — одни списки, зеркальная настройка

**Из России.** Российское и китайское идёт напрямую, остальное — в туннель.
Так работает быстрее и не ломаются банки с маркетплейсами: они не любят
заходов с зарубежного адреса.

**Из-за границы (Аргентина).** Ровно наоборот: **через туннель идёт как раз
российское**, чтобы попасть в банк и личные кабинеты как из дома, а всё
остальное — напрямую по месту. Списки те же самые, меняется только сторона.

## Как подключить

### Happ (телефон)

В настройках маршрутизации:
- **Прямо (Direct):** `geoip:ru`, `geoip:cn` и содержимое `direct-domains.txt`
- **Через прокси:** всё остальное

Готовые конфигурации лежат в `happ/`: `iz-rossii.json` и `iz-argentiny.json`.
Открываются ссылкой вида `happ://routing/add/<конфигурация в base64>`.

### MikroTik (роутер)

Скрипт `scripts/mikrotik-import.rsc` наполняет `address-list` из этих файлов.

⚠️ **Считайте память.** На плате hAP ac² (256 МБ) замер показал: **7 274 записи
занимают 22 МБ**. Полный список RU+CN — это 14 163 записи, то есть около 42 МБ.
Влезет, но заранее посмотрите, сколько памяти свободно: `/system resource print`.

⚠️ **И не удаляйте список одной командой.** `remove [find list=...]` на семи
тысячах записей грузит процессор на минуты, и на это время роутер перестаёт
успевать обслуживать сеть. Удаляйте частями.

### Xray / sing-box (сервер или компьютер)

Префиксы из `lists/*.txt` кладутся прямо в правило маршрутизации, поле `ip`.
Геобаза при этом не нужна вовсе — экономит десятки мегабайт памяти.

## Обновление

Раз в неделю по расписанию GitHub Actions, плюс кнопкой вручную.
Локально: `python3 scripts/build.py`.

## Источники

- [ipverse/rir-ip](https://github.com/ipverse/rir-ip) — агрегированные префиксы
  региональных интернет-реестров, обновление ежедневное.

Списки содержат только публичные данные реестров. Ключей, паролей и адресов
серверов здесь нет и не будет.
